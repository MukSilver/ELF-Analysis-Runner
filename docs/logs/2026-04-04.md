## 막힌 점

- Canary 코드를 어디에 넣어야 하는지 계속 헷갈렸다.

- except를 없애야 하나, 유지해야 하나 잠깐 헷갈렸다.

## 해결한 점
- RELRO는 PT_GNU_RELRO + BIND_NOW 조합으로 생각하면 된다는 걸 정리했다.
- Canary 코드는 정상 분석 흐름 안에서, return 바로 전에 있어야 한다는 걸 이해했다.
- except는 없애는 게 아니라, 예외 처리 전용으로 남겨야 한다는 구조를 확실히 잡았다.
